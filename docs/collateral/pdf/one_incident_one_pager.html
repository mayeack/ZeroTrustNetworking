THE RISKY CONNECTION, IN THIS EXAMPLE

A contractor's merge request adds a post-build script to a machine-learning repository. When the CI job runs, the build runner uses curl to copy model checkpoint files, the weights of a 512-GPU training run, from the protected training store. Nothing was hacked: the runner simply had network reach it shouldn't, and the store's new allowlist was still in audit mode, so the copy went through.

Cisco Isovalent observes it: Hubble records the connection with both workload identities and its policy verdict; Tetragon names the program that opened it. Splunk correlates it with the workload, the CI job and the server, raises one finding, and an agent gathers the evidence. A SOAR playbook enforces at the nearest point once a person approves; the posture dashboard proves it.
