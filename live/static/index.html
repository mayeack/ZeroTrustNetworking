Settings

Cadence, modes and where the streaming runs.

Cadence

Fast runs every scheduled search each minute; normal runs them every five minutes.

Response mode

Local: the approvals page and the app's endpoint apply the policy. SOAR: the ES automation rule hands the finding to the playbook. Switching also turns the ES automation rule on (SOAR) or off (Local).

Agent mode

MCP: the agent calls the five MCP tools. Inline: the evidence is gathered by a search and handed to the agent in one prompt.

Streaming ownership

While this app runs it holds the streaming lease; the search head's scripted input stands down and takes over again when this app stops.
